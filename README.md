# VICTORIA UNIVERSE — GitHub Pages

Готовий статичний сайт на основі фінального макета. Збирання й встановлення залежностей не потрібні.

## Публікація

1. Розпакуйте ZIP.
2. Завантажте всі файли з архіву в корінь репозиторію. Файл index.html має бути в корені, без додаткової папки навколо нього.
3. Увімкніть GitHub Pages для гілки з цими файлами та публікуйте корінь репозиторію.

Завантажувати потрібно розпаковані файли, а не сам ZIP.

## Файли

- index.html — головна сторінка портфоліо.
- universe.html — незмінена 3D-інсталяція першого екрана.
- elevenlabs-concept.html — оригінальна підсторінка ElevenLabs із DIVE INTO THE FUTURE під логотипом.
- media-player-preview.html — візуальна демонстрація плеєра зі збільшеною анімованою кулею.
- photo-resizer-preview.html — статичний оригінальний інтерфейс Resizer.
- .nojekyll — статична публікація без обробки Jekyll.

Усі зображення й графічні залежності цих сторінок вбудовані у HTML. Посилання на зовнішні сайти й трейлер YouTube збережені з фінального макета. Для анімованої 3D-інсталяції потрібен браузер із WebGL.

Оформлення головної сторінки, сцена й три підсторінки збережені. Пакування змінює лише спосіб завантаження: підсторінки відкриваються з окремих HTML-файлів у тому самому переглядачі портфоліо.
